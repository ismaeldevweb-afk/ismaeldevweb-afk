## 🚀 Projetos em destaque

### 🔎 [DevSignal](https://github.com/ismaeldevweb-afk/DevSignal)

Aplicação para **analisar portfólios no GitHub e documentos profissionais em PDF**, identificar pontos fortes e oportunidades de melhoria e ajudar no planejamento da evolução profissional.

- Frontend em **React, Vite e Tailwind CSS**.
- Backend em **Node.js, Express e SQLite**.
- Integração com a API pública do GitHub e análise de arquivos PDF.
- Recomendações baseadas em **regras e heurísticas transparentes**, sem depender de IA paga.

**[Explorar código →](https://github.com/ismaeldevweb-afk/DevSignal)**

### 📄 [CV Criador](https://github.com/ismaeldevweb-afk/cvCriador)

Plataforma web para **montar e personalizar currículos**, com editor visual, visualização em tempo real e exportação em PDF.

- Interface em **React, Vite e Tailwind CSS**.
- API em **Node.js e Express** e exportação com **Puppeteer**.
- Importação de informações a partir do GitHub e de arquivos PDF.
- Persistência local no navegador; recursos de IA experimentais/simulados.

**[Explorar código →](https://github.com/ismaeldevweb-afk/cvCriador)** · **[Ver aplicação →](https://cv-criador.vercel.app)**

### 🌐 [Ismael Dev Studio](https://github.com/ismaeldevweb-afk/Ismael-Dev-Studio)

Site de apresentação de **serviços de desenvolvimento web**, com foco em sites profissionais, landing pages e presença digital para negócios.

- Desenvolvido com **Next.js, TypeScript, React e Tailwind CSS**.
- Estrutura para páginas de serviços, planos e contatos.
- Cuidados com **SEO, responsividade e segurança**.

**[Explorar código →](https://github.com/ismaeldevweb-afk/Ismael-Dev-Studio)** · **[Visitar site →](https://ismaeldevstudio.vercel.app)**

### ✍️ [Eu + IA](https://github.com/ismaeldevweb-afk/eu-ia-eta)

Blog de tecnologia dedicado a **registrar experiências de desenvolvimento com apoio de inteligência artificial**, incluindo decisões, aprendizados e bastidores dos projetos.

- Desenvolvido com **Next.js, React e TypeScript**.
- Publicação de artigos em Markdown.
